# Imágenes del proyecto

Capturas y previsualizaciones de la web de GP50 Custom Studio (editor 0.9.2 / firmware v11.1). Las pantallas del editor se muestran en modo demo; los temas y las animaciones son previsualizaciones de la pantalla del pedal.

Estas imágenes documentan el proyecto y no modifican las licencias del editor, los componentes de terceros ni el firmware original de Valeton.
